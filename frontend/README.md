# Career Gap Analyzer - Frontend (React + Vite)

## Run
1. Install Node.js LTS from nodejs.org (one time).
2. Start the backend first (uvicorn app.main:app --reload in the backend folder).
3. In this folder:

    npm install
    npm run dev

4. Open http://localhost:5173  (use "localhost", not 127.0.0.1, because the backend allows that origin).

The API address defaults to http://localhost:8000. To change it, copy .env.example to .env and edit it.
